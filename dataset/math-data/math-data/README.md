# Math Evaluation Dataset

A tiered benchmark dataset for evaluating math reasoning, ranging from grade-school word problems to IMO-level olympiad questions.

## Directory Structure

```
.
├── L1_Basic/              # Elementary / middle school word problems
│   ├── raw/               # Raw sampled JSONL files
│   ├── processed/         # Processed / normalized versions (to be added)
│   └── metadata/          # Per-source metadata (to be added)
├── L2_Medium/             # High school / gaokao / MATH Level 2-3
├── L3_Hard/               # Competition math / OlympiadBench / Omni-MATH / AMC12
├── L4_Expert/             # AIME / AMC / IMO-level problems
├── all_problems.jsonl     # Unified file containing all 182 records
├── dataset_index.json     # Per-file record counts
├── download_summary.json  # Aggregate counts by level and source
└── README.md              # This file
```

## Record Schema

Every record is a JSON object with these fields:

| Field     | Description                                      |
|-----------|--------------------------------------------------|
| `id`      | Unique identifier within the file                |
| `level`   | Difficulty bucket: `L1_Basic`, `L2_Medium`, `L3_Hard`, `L4_Expert` |
| `source`  | Dataset source (e.g., `GSM8K`, `MATH`, `AIME 2025 I`) |
| `problem` | Question text (LaTeX supported)                  |
| `answer`  | Final answer (numeric, expression, or choice)    |
| `solution`| Step-by-step solution when available; `null` otherwise |

## Reproducibility

Sampling uses a fixed random seed (`42`). The `all_problems.jsonl` file is the canonical union of all `L*/raw/*.jsonl` files and can be regenerated by running the scripts in the repository or by re-executing the download commands.

## Notes & Caveats

- Some datasets (AGIEval, OlympiadBench, AMC/AIME from HF) do not provide worked solutions; in those cases `solution` is set to `null`.
- OlympiadBench is multimodal; the records here contain only the textual problem and answer.
- HuggingFace downloads were performed without authentication; a `HF_TOKEN` is recommended for higher rate limits.
