## 解答题参考答案（分步要点，保留原评分点）

**15.** (1) 取 CC₁ 中点 F，BC 中点 G，连接 EF、FG、DG。
- △ACC₁ 中，E、F 为 AC₁、CC₁ 中点 ⇒ EF // AC，EF = ½AC；△ABC 中，D、G 为 AB、BC 中点 ⇒ DG // AC，DG = ½AC（2 分）
- ⇒ EF // DG 且 EF = DG ⇒ 四边形 EDGF 为平行四边形 ⇒ DE // FG（4 分）
- FG ⊂ 平面 BCC₁B₁，DE ⊄ 平面 BCC₁B₁ ⇒ DE // 平面 BCC₁B₁（5 分）

(2) 取 AC 中点 H，连接 DH、EH。D、H 为 AB、AC 中点 ⇒ DH // BC。直三棱柱 ⇒ CC₁ ⊥ 平面 ABC；∠ACB=90° ⇒ AC ⊥ BC；AC∩CC₁=C ⇒ BC ⊥ 平面 ACC₁A₁ ⇒ DH ⊥ 平面 ACC₁A₁，垂足为 H，DE 与平面 ACC₁A₁ 所成角为 45°（7 分）
- EH 为中位线 ⇒ EH = ½CC₁ = 1；Rt△DHE 中 DH = EH·tan45° = 1 ⇒ BC = 2DH = 2，AC = BC = 2【原件此处"BC=2DH=1"应为笔误，按 AC=BC=2 理解】（10 分）
- DE // 平面 BCC₁B₁ ⇒ 所求距离 = D 到平面 BCC₁B₁ 的距离；DG // AC，AC ⊥ 平面 BCC₁B₁ ⇒ DG ⊥ 平面 BCC₁B₁，DG = ½AC = 1
- **直线 DE 到平面 BCC₁B₁ 的距离为 1**（13 分）

**16.** (1) AC² = AB² + BC² − 2·AB·BC·cosB = 9 + 12 − 2×3×2√3×(√3/3) = 9 ⇒ AC = 3（3 分）
- **cos A = (AB² + AC² − BC²)/(2·AB·AC) = (9+9−12)/18 = 1/3**（6 分）

(2) 设 AD→ = −λAB→ (λ>0)，DE // BC 设 DE→ = μBC→。
- AE→ = −(λ+μ)AB→ + μAC→（8 分）；AE⊥AC ⇒ −(λ+μ)AB→·AC→ + μAC→² = 0；AB→·AC→ = 3×3×(1/3) = 3，AC→² = 9 ⇒ λ = 2μ（11 分）
- |DE→| = μ|BC→| ⇒ √6 = 2√3 μ ⇒ μ = √2/2
- CE→² = (9/2)AB→²·… 展开代入 = 45 ⇒ **CE = 3√5**（15 分）

**17.** (1) X = 1, 2, 3, 4（1 分）
- P(X=1) = p = 1/3；P(X=2) = (1−p)p = 2/9；P(X=3) = (1−p)²p = 4/27；P(X=4) = (1−p)³p + (1−p)⁴ = (1−p)³ = 8/27（4 分）

(2)(ⅰ) X > k ⟺ 前 k 次均未投中 ⇒ **P(X>k) = (1−p)ᵏ**（9 分）
(ⅱ) m ∈ N ⇒ {X>k+m} ⊆ {X>k} ⇒ P(X>k+m | X>k) = P(X>k+m)/P(X>k)（12 分）
- 由 (ⅰ)：P(X>k+m) = (1−p)^(k+m)，P(X>k) = (1−p)ᵏ ⇒ 比值 = (1−p)ᵐ = P(X>m)，得证（15 分）

**18.** (1) c = 1，e = c/a = 1/2 ⇒ a = 2；b² = a² − c² = 3 ⇒ **C: x²/4 + y²/3 = 1**（3 分）

(2) 设 l: y = k(x+1) (k>0)，P(x₁,y₁)，Q(x₂,y₂)。联立椭圆消 y：(3+4k²)x² + 8k²x + 4k² − 12 = 0，韦达：x₁+x₂ = −8k²/(3+4k²)，x₁x₂ = (4k²−12)/(3+4k²)；由对称性 R(−x₁,−y₁)（5 分）

(ⅰ) S△PQR = 2S△PQO，S△PQO = ½(|y₁|+|y₂|) = ½(y₁−y₂)（因 Q 在第三象限 x₂<−1, y₂<0，y₁>0）⇒ S△PQR = y₁ − y₂。S△PFO = ½y₁ ⇒ y₁ − y₂ = 3y₁/2 ⇒ y₁ = −2y₂ ⇒ x₁ = −2x₂ − 3（7 分）
- 代入韦达：x₂ = (−9−4k²)/(3+4k²)，x₁ = (9−4k²)/(3+4k²)；由 x₁x₂ = (4k²−12)/(3+4k²) 化简得 36k² = 45 ⇒ **k = √5/2，l: √5 x − 2y + √5 = 0**（10 分）

(ⅱ) k_PQ = k；k_QR = (y₁+y₂)/(x₁+x₂) = k(1 + 2/(x₁+x₂)) = k[1 + 2(3+4k²)/(−8k²)] = −3/(4k)（13 分）
- tan∠PQR = |(k_PQ − k_QR)/(1 + k_PQ·k_QR)| = |(k + 3/4k)/(1 − 3/4)| = 4(k + 3/4k) ≥ 4·2√(k·3/4k) = **4√3**（当且仅当 k = √3/2 取等）（15 分）
- **tan∠PQR 的最小值为 4√3**（17 分）

**19.** (1) f(−1) = 2⁻¹ = ½，D(−1) = {d | f(−1+d) > ½}，令 t = −1+d（1 分）
- t<0 时 f(t) = 2ᵗ > ½ ⟺ t > −1 ⇒ −1<t<0；t≥0 时 f(t) = 1−t > ½ ⟺ t < ½ ⇒ 0≤t<½（2~3 分）
- 综上 t ∈ (−1, ½) ⇒ d = t+1 ∈ (0, 3/2) ⇒ **D(−1) = {d ∈ R | 0 < d < 3/2}**（4 分）

(2) f 为奇函数：x>0 时 f(x) = −2⁻ˣ，f(0)=0（5 分）
- x<0 时：D(x) = (0, −x)；x>0 时：D(x) = (−∞, −x] ∪ (0, +∞)（7 分）
- 分四情形（x₁,x₂ 同负/同正/x₁>0,x₂<0/x₁<0,x₂>0）逐一验证 D(x₂) ⊆ D(x₁)，第四情形与 f(x₁)≤f(x₂) 矛盾 ⇒ 得证（9 分）

(3)(ⅰ) 反证：假设 f(0) < 1。
- 若 f(0) ≤ 0：取 x₁ = −½，f(x₁) = 2^(−½) > 0 > f(0) ⇒ D(0) ⊇ D(x₁)；取 d = ¼ ∈ D(x₁) ⇒ f(¼) > f(0)，与条件② f(¼) < f(0) 矛盾（11 分）
- 若 0 < f(0) < 1：令 x₀ = log₂ f(0) < 0，则 f(x₀) = f(0) ⇒ D(x₀) = D(0)；取 d₀ = min{−x₀/2, ½}，由②知 d₀ ∉ D(0)，但可证 d₀ ∈ D(x₀)，矛盾
- ⇒ **f(0) ≥ 1**（13 分）

(ⅱ) 先证 ∀x ∈ (0,1)，f(x) ≤ 0：假设 f(x) > 0，取 c<0 使 f(c) = 2ᶜ < f(x)，由① D(c) ⊇ D(x)，可推 −x ∈ D(x) 即 f(c−x) > f(c)，与 x<0 段 f 单调增矛盾（14 分）
- 再证 ∀x > 0，f(x) ≤ 0（x≥1 情形同理构造 b' = ½ −(x−b) 引出矛盾）（15 分）
- 取 0 < x < y：f[−(y−x)−1] = 2^(−(y−x)−1) > 0 ≥ f(x) ⇒ 由① D(x) ⊇ D[−(y−x)−1]，可推出 y−x ∈ D(x) ⇒ f(y) > f(x)
- ⇒ **f(x) 在 (0, +∞) 单调递增，得证**（17 分）
